# SpeadyAnimation Context for Code Generation

Use this file as the source of truth when generating SpeadyAnimation scenes.
The main goals are:
- generate runnable code
- use the public API only
- keep layouts clean and readable
- render math with `MathTex`, not `Text`

## 1. Project Model

SpeadyAnimation is a lightweight, Manim-style animation library built on Pygame.
It has three core concepts:
- `Scene`: the script and timeline
- `Mobject`: anything visible on screen
- `Animation`: timed changes to mobjects

Prefer the top-level import:

```python
from speadyanimation import *
```

## 2. Hard Rules

- Output runnable Python only.
- Use only APIs exposed by `speadyanimation`.
- Keep the scene minimal and uncluttered.
- Remove or fade out old elements before adding new ones if space gets tight.
- Do not guess methods that do not exist in this codebase.
- Prefer direct, explicit scene code over clever abstractions.

## 3. Math and Text

Math must be rendered with `MathTex`.

- Use raw strings for math, for example `MathTex(r"\sin(x)")`.
- Do not put math-like content inside `Text`, including `x^2`, `f'(x)`, `\frac{...}{...}`, or Greek letters.
- If a label mixes prose and math, split it into separate objects.
- If you need one mixed object, keep the math in `MathTex` and the prose in `Text`.

Good examples:

```python
equation = MathTex(r"f(x) = x^2")
title = Group(Text("Derivative of"), MathTex(r"x^2")).arrange(RIGHT, buff=0.2)
subtitle = Group(Text("The slope of y ="), MathTex(r"x^2"), Text("is twice the x-value")).arrange(RIGHT, buff=0.2)
```

Bad example:

```python
title = Text("Derivative of x^2")
```

## 4. Layout Rules

Spacing matters more than complexity.

- Use `to_edge(UP)` for titles.
- Use `next_to(..., DOWN, buff=0.6 to 1.0)` for equations and subtitles.
- Keep at least `0.8` units of breathing room between major blocks when possible.
- If a graph is on screen, keep labels outside the plotted region.
- Default `buff` should usually be `0.6` or larger.

Safe pattern:

```python
title = Text("Some Title").to_edge(UP)
equation = MathTex(r"f(x)=x^2").next_to(title, DOWN, buff=0.8)
axes = Axes(...).move_to([0, -0.5])
```

## 5. Core API

### Scene

Typical structure:

```python
class MyScene(Scene):
    def construct(self):
        ...

if __name__ == "__main__":
    MyScene().render(preview=True, export=True, filename="speadystudioanimation.mp4")
```

Useful methods:
- `self.add(*mobjects)`
- `self.remove(*mobjects)`
- `self.play(*animations, run_time=None, rate_func=None)`
- `self.wait(duration=1.0)`

### Mobjects

Common classes:
- Geometry: `Dot`, `Circle`, `Arc`, `Line`, `Arrow`, `DashedLine`, `Rectangle`, `Square`, `Polygon`, `RegularPolygon`, `Triangle`, `Annulus`, `PointCloud`
- Graphing: `NumberLine`, `Axes`, `NumberPlane`, `FunctionGraph`, `ParametricGraph`, `BarChart`
- Text: `Text`, `MathTex`, `Paragraph`
- Grouping: `Group`, `VGroup`
- Media: `ImageMobject`

Common positioning helpers:
- `move_to(point)`
- `shift(vector)`
- `next_to(other, direction, buff=0.25)`
- `to_edge(direction, buff=0.25)`
- `align_to(other, direction)`
- `arrange(...)` on groups

### Animations

Common classes:
- Creation: `Create`, `Uncreate`, `DrawBorderThenFill`, `Write`, `ShowPassingFlash`
- Movement: `Shift`, `MoveTo`, `Rotate`, `ScaleInPlace`, `MoveAlongPath`
- Fading: `FadeIn`, `FadeOut`, `FadeTransform`, `GrowFromCenter`
- Transform: `Transform`, `ReplacementTransform`, `CounterclockwiseTransform`, `TransformFromCopy`
- Indication: `Indicate`, `Flash`, `Circumscribe`, `Wiggle`
- Composition: `AnimationGroup`, `Succession`, `LaggedStart`, `Wait`

## 6. Animation Flow

Recommended defaults:
- simple draw-in: `1.0` to `1.5` seconds
- small emphasis: `0.2` to `0.5` seconds
- pause: `self.wait(0.5)` or `self.wait(1.0)`

Good scene flow:
1. Introduce the title
2. Show the equation
3. Build the graph or diagram
4. Add supporting labels
5. Highlight the insight
6. Clean the scene
7. End with a short conclusion

## 7. Export Template

Use this template for new scenes:

```python
import sys, os, math
import numpy as np

sys.path.insert(0, os.path.abspath(os.path.dirname(__file__)))

from speadyanimation import *

Config.FPS = 24


class AnimationName(Scene):
    def construct(self):
        pass


if __name__ == "__main__":
    AnimationName().render(
        preview=True,
        export=True,
        filename="speadystudioanimation.mp4",
    )
```

## 8. Final Checklist

- use `from speadyanimation import *`
- use `MathTex` for all mathematical notation
- split mixed text/math labels instead of forcing them into `Text`
- keep text away from graphs
- use actual classes and methods from this repository only
- include `if __name__ == "__main__":`
- keep `Config.FPS = 24` unless told otherwise
